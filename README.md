## Assignment Description

This repository contains practical work completed for the Git Version Control assignment. It demonstrates repository setup, file tracking, commits, branching, merging, conflict resolution, and working with remote repositories.

## Practical Files

The available practical files have been organized into the following folders:

- `exercise-01/` — Greeting script (`greet.sh`) with input validation.
- `exercise-02/` — Practice text files (`file1.txt` and `file2.txt`).
- `exercise-03/` — Git ignore rules (`.gitignore`) for generated and private files.
- `exercise-04/` — Interactive menu script (`menu.sh`).
- `exercise-05/` — Help instructions (`help.txt`).
- `exercise-06/` — Merge-conflict practice file (`mode.txt`).
- `exercise-07/` — Remote-fetch practice file (`fetch-demo.txt`).
- `exercise-08/` — Two-clone challenge files (`q19-demo.txt` and `q19-second.txt`).

## Instructions to Run the Programs

Use Git Bash on Windows or another Bash-compatible terminal.

### Greeting Script

```bash
bash exercise-01/greet.sh
```

Enter a name when prompted. The script validates empty input and displays a greeting for a valid name.

### Menu Script

```bash
bash exercise-04/menu.sh
```

Follow the displayed menu instructions.

The remaining files are used for Git practice and repository operations rather than being standalone programs.
