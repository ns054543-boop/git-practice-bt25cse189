\## Assignment Description



This assignment demonstrates the use of Git and GitHub for version control, including repository creation, staging and committing changes, branching, merging, conflict resolution, remote repositories, and collaboration.



\## Completed Exercises



The practical exercises are organized into the following folders:



\- `exercise-01` — Check Git version and configure Git identity.

\- `exercise-02` — Create a project README and make the initial commit.

\- `exercise-03` — Create a greeting script and validate empty input.

\- `exercise-04` — Create and commit practice files.

\- `exercise-05` — Inspect staged and unstaged changes with `git diff`.

\- `exercise-06` — Ignore generated and private files using `.gitignore`.

\- `exercise-07` — Create a menu script on a feature branch.

\- `exercise-08` — Add help instructions and merge a feature branch.

\- `exercise-09` — Create and resolve a merge conflict.

\- `exercise-10` — Inspect and discard temporary working-tree changes.

\- `exercise-11` — Revert a temporary commit.

\- `exercise-12` — Stash unfinished work and restore it.

\- `exercise-13` — Initialize a team repository and configure a remote.

\- `exercise-14` — Collaborate using a feature branch and pull request.

\- `exercise-15` — Fetch and update a clone.

\- `exercise-16` — Practise the Git workflow in Visual Studio Code.

\- `exercise-17` — Resolve an add/add conflict in VS Code.

\- `exercise-18` — Verify scripts, create a release tag, and inspect history.

\- `exercise-19` — Complete the two-clone repository challenge.
