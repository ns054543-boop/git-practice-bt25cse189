\# Git Commands and Practice Record



| Command | Purpose |

|---|---|

| git --version | Check installed Git version |

| git config | Configure Git identity |

| git init -b main | Initialize a repository |

| git status | Check repository status |

| git add | Stage files |

| git commit | Save changes |

| git log --oneline | View commit history |

| git diff | Inspect unstaged changes |

| git diff --staged | Inspect staged changes |

| git switch -c | Create and switch to a branch |

| git merge | Merge branches |

| git restore --staged | Unstage changes |

| git restore | Discard unstaged changes |

| git revert | Undo a commit with a new commit |

| git stash | Temporarily save working changes |

| git clone | Clone a remote repository |

| git remote -v | Display remote URLs |

| git fetch | Download remote updates |

| git pull | Fetch and integrate remote changes |

| git push | Publish commits |

| git tag -a | Create an annotated tag |
